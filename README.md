# PHP CI/CD Laboratory Project

This repository contains a minimal PHP application developed as part of Laboratory Work No. 1.

## Project purpose

The project demonstrates version control with Git and GitHub, automated code quality checks, unit testing, and CI/CD pipeline configuration using GitHub Actions.

## Technologies

- PHP 8.2
- Git and GitHub
- GitHub Actions
- PHPUnit
- Laravel Pint
- Composer

## Planned functionality

- Basic calculator operations.
- Automated code formatting checks.
- Unit testing.
- Continuous Integration workflow.
